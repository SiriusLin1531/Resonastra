# Contributing to Resonastra

Keep changes focused and preserve the fully local/offline default.

Do not commit model weights, runtime bundles, user data, caches, credentials, or generated outputs.

Preserve third-party notices and avoid unnecessary compatibility-breaking renames of internal VoiceLab or voicelab identifiers that remain part of the v1.0.0 compatibility surface.

Keep public branding canonical: Resonastra / RESONASTRA.
